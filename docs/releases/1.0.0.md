# MusicCurator 1.0.0

MusicCurator helps curate a Nextcloud music library with metadata lookup,
cover artwork, batch review, file organization and managed M3U8 playlists.
It complements Nextcloud Music and other compatible players.

This release includes coordinated Vue, ESLint, Stylelint and OpenAPI updates,
restored GitHub checks, and an npm vulnerability gate. Nextcloud 34 and 35 are
supported. Existing PHP analysis findings remain documented in docs/ci.md;
the CI baseline prevents additional findings but does not resolve the backlog.

MP3 tag writing remains experimental. Test write operations on backed-up music.
The optional AI Advisor remains advisory and does not automatically write tags
or move files.

Install the signed musiccurator-1.0.0.tar.gz asset rather than GitHub's automatic
source archives, which do not contain the compiled frontend or app signature.
